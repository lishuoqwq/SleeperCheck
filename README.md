## 📱 项目简介

SleeperCheck 是一款极致简洁、本地优先且低功耗的睡眠习惯记录 APP。通过回顾式查询系统使用统计，帮助用户记录和改善睡眠习惯。

## ✨ 已实现功能

### 🎨 UI 设计升级 (v1.0.0)
- ✅ **现代化设计风格** - 参考优秀设计，采用柔和蓝紫渐变色系
- ✅ **统一视觉语言** - 大圆角卡片（20dp）、轻微阴影、清晰层次
- ✅ **完整配色系统** - 主色调、辅助色、文字颜色三级层次
- ✅ **渐变背景资源** - 蓝紫渐变、圆角卡片背景

### 🏠 主页功能
- ✅ **智能问候语** - 根据时间显示不同问候（凌晨/下午/晚上/深夜）
- ✅ **本周概览卡片** - 显示本周打卡次数和贤者模式统计
- ✅ **健康小贴士** - 随机显示7条睡眠健康建议
- ✅ **打卡成功动画** - 缩放动画效果，提升用户满足感
- ✅ **睡眠检测** - 基于 UsageStatsManager 自动判断熬夜

### 📊 统计页功能
- ✅ **渐变色柱状图** - 早睡蓝色渐变、熬夜红色渐变
- ✅ **本月概览** - 打卡天数、熬夜天数、达标率统计
- ✅ **最近7天** - 可视化展示每日打卡情况
- ✅ **优化视觉效果** - 更大圆角、优化文字颜色和大小

### 🏆 成就系统
- ✅ **三级成就徽章**
  - 🌟 早睡新手：连续打卡3天
  - 🔥 坚持达人：连续打卡7天
  - 👑 早睡王者：连续打卡30天
- ✅ **自动解锁显示** - 达成成就后显示蓝色勾选标记

### 💾 数据管理
- ✅ **数据导出** - JSON 格式备份所有打卡记录
- ✅ **数据导入** - 从备份文件恢复数据
- ✅ **本地存储** - 所有数据本地存储，保护隐私

### 🔒 核心特性
- ✅ **隐私至上** - 无网络权限，所有数据本地存储
- ✅ **低功耗** - 回顾式查询，无常驻后台服务
- ✅ **连续打卡记录** - 自动计算最长连续打卡天数
- ✅ **月度统计** - 自动生成月度打卡统计报告

## 🏗️ 技术架构

- **语言**: Kotlin
- **最低版本**: Android 8.0 (API 26)
- **架构**: MVVM + Repository
- **数据库**: Room (SQLite)
- **偏好设置**: DataStore
- **后台任务**: WorkManager
- **UI**: ViewBinding + Material Design 3

## 📦 构建说明

### 前置要求

- Android Studio Hedgehog | 2023.1.1 或更高版本
- JDK 17
- Android SDK 34

### 构建步骤

1. 克隆项目
```bash
git clone https://github.com/yourusername/are_you_sleep.git
cd are_you_sleep
```

2. 使用 Android Studio 打开项目

3. 等待 Gradle 同步完成

4. 运行项目或构建 APK
```bash
./gradlew assembleRelease
```

## 🚀 GitHub Actions 自动构建

项目已配置 GitHub Actions，每次推送到 master/main 分支时会自动构建 APK。

构建产物可在 Actions 页面的 Artifacts 中下载。
